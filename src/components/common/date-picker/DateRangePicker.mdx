# DateRangePicker

Seleciona um intervalo completo com início e fim usando os campos segmentados e o RangeCalendar do HeroUI. Para uma data única, use [DatePicker](?path=/docs/componentes-datepicker-data-única--docs).

## Uso controlado

```tsx
import { useState } from 'react';
import { parseDate, type CalendarDate } from '@internationalized/date';
import { DateRangePicker } from '@/components/common/date-picker';

const [period, setPeriod] = useState<{ start: CalendarDate; end: CalendarDate } | null>(null);

<DateRangePicker
  label="Período de publicação"
  value={period}
  onChange={setPeriod}
  minValue={parseDate('2026-01-01')}
/>
```

`value`/`defaultValue` seguem o HeroUI: um objeto com dois `DateValue` ou `null` para nenhum intervalo. O callback recebe o intervalo completo; a primeira escolha no calendário inicia a seleção e a segunda a conclui. Um início isolado ainda não é um intervalo aplicado. Os campos permitem editar as datas por segmentos e `granularity` acrescenta horário quando os valores são `CalendarDateTime`.

Não exige FormProvider. Para React Hook Form, conecte com `Controller` e faça as validações de domínio no schema. `minValue`/`maxValue` restringem as datas; `isDateUnavailable` e `validate` permanecem disponíveis pelo contrato do HeroUI. `isInvalid`/`errorMessage` integram erros externos. O idioma é `pt-BR`, configurado pelo próprio componente.

## Integração e migração

Importe `DateRangePicker` pelo mesmo index de `DatePicker`, sem `mode="range"`. Use `isDisabled` no lugar de `disabled` e `minValue`/`maxValue` no lugar de strings `minDate`/`maxDate`. Com `CalendarDateTime` e granularidade de horário, os horários podem ser editados nos segmentos do campo. Teclado, foco, escolha de ano e seleção de datas seguem o HeroUI.

No filtro de publicações, novos limites civis representam dias locais completos, convertidos em instantes UTC pela tela consumidora. Limites já existentes preservam a precisão se sua data não mudar. Um filtro recebido pela URL com apenas um limite continua ativo e é descrito abaixo do campo; uma nova escolha o substitui por intervalo completo. A limpeza permanece nas ações dos filtros.

As stories usam estado local sem backend. Não comprovam conversões da API ou fluxos autenticados. Referência: [DateRangePicker do HeroUI](https://heroui.com/en/docs/react/components/date-range-picker). Testes automatizados não certificam acessibilidade completa.

Os campos segmentados no topo do calendário permitem editar a data e, quando disponível, o horário em 24 horas. Os segundos não são exibidos; alterar hora ou minuto define segundos e fração como zero.
